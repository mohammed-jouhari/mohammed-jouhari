- Space–Air–Ground–Sea Integrated Networks (SAGSIN)
- AI-native networks
- Cybersecurity and IoT security

## Selected research repositories

- **[PIML-SAGSIN-Survey](https://github.com/mohammed-jouhari/PIML-SAGSIN-Survey)** — Resources for a survey and tutorial on physics-informed machine learning for SAGSIN.
- **[sagin-mfg-matlab-simulations](https://github.com/mohammed-jouhari/sagin-mfg-matlab-simulations)** — MATLAB simulations for mean-field-game-based orchestration in Space–Air–Ground Integrated Networks.
- **[computing-in-the-gaps](https://github.com/mohammed-jouhari/computing-in-the-gaps)** — Seabed-to-orbit edge-computing simulation.
- **[iot-ids-lightweight](https://github.com/mohammed-jouhari/iot-ids-lightweight)** — Research code for lightweight IoT intrusion detection.
